# Useful tools

Tools that can help during the KNX workshop and when developing your own applications.

## nrfutil

Nordic's command-line tool for tasks such as device discovery, programming, and SDK and toolchain management through installable commands. Useful for scripting and automating development tasks.

- [Overview and download](https://www.nordicsemi.com/Products/Development-tools/nRF-Util)

## nRF Connect for VS Code

Nordic's extension pack for developing nRF Connect SDK applications in Visual Studio Code. Use it to manage SDKs and toolchains, configure and build applications, and flash and debug devices.

- [Overview](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-VS-Code)
- [Install the extension pack](https://marketplace.visualstudio.com/items?itemName=nordic-semiconductor.nrf-connect-extension-pack)

## nRF Connect for Desktop

A desktop launcher for Nordic development applications, including Programmer, Serial Terminal, and Power Profiler. Install the individual applications you need from within the launcher.

- [Overview and download](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-Desktop)

## Power Profiler Kit

The Power Profiler Kit II (PPK2) is hardware for measuring a device's current consumption. Use it with the Power Profiler application in nRF Connect for Desktop to inspect sleep current and activity peaks, such as Thread polling and radio transmissions.

- [PPK2 overview and documentation](https://www.nordicsemi.com/Products/Development-hardware/Power-Profiler-Kit-2)
- [Power Profiler application](https://github.com/NordicSemiconductor/pc-nrfconnect-ppk)
